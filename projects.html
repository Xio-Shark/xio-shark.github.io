xioflow · Agent 受监督执行内核与多智能体运行时

TypeScript · SQLite (WAL) · 零运行时依赖 · npm: @xioflow/kernel

Agent 运行时通常调一次 spawn() 然后听天由命：宿主在工具调用中途崩溃、取消无法确认时，留下的是孤儿进程、重复生效的副作用、以及对「实际发生了什么」的无记录。xioflow 把这些状态变成一等公民：

  • 意图先持久化再拉起进程，结果不可判定时记为 indeterminate 并保留租约，重启绝不盲目重放；
  • 按操作 ID（opId）实现幂等：同指纹重投直接复用记录的结果，指纹不同报错；
  • 终止按 SIGINT → SIGTERM → SIGKILL 对进程组升级，并重新枚举逃逸（setsid）后代；无法确认就诚实上报残留 PID；
  • 工作区快照 / 按步回滚 / 分叉，回滚范围按指纹校验，绝不动声明范围外的文件；
  • 三锁分离（OS 排他锁、SQLite WAL 写锁、资源租约）支撑多入口共用同一执行域，代际栅栏隔离过期属主。

核心 172 项单测（含 44 项共享契约），CI 覆盖 Node 22/24、Ubuntu 与 macOS。附四个可运行集成示例（替换 subprocess 封装 / Temporal activity / LangGraph 节点 / MCP stdio 传输）。执行层正确性有公开的故障注入对照实验背书。

TypeScript · Node.js · npm 与 Homebrew 可安装
